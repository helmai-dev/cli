# Helm GTM filter

Locked 2026-08-31 from Josh, from the Cursor GTM teardown (build / spread / convert). Helm copies the plays, not the ARR story. Use this to fail a change that is plugin-shaped, demo-shaped, or sales-shaped.

Read `docs/NORTH_STAR.md` first. This file does not replace it.

## Act 1 — enter with near-zero switching cost

Helm's fork analog is `helm proxy` / wrap (`ANTHROPIC_BASE_URL` or equivalent). Developers keep Cursor and their editor. Helm sits on the request path.

A plugin gives a seat. The wrap gives the table.

Hook-based teammate-on-path notices, MCP-only awareness, and a nicer dashboard are complementary, not the product. Fail a change that turns Helm into the plugin.

## Act 2 — let the product distribute itself

Word of mouth needs a screenshot that needs no caption. A spend chart is not that. Intercepting waste on the path (reuse, skip, cheaper model) is.

Freemium: easy install / wrap stays free until usage hits a natural limit. Do not gate the wrap behind a paywall. Do not optimize for the demo — no fake savings, no fake dashboards.

Public founder marketing is off. Josh is not announcing himself as Helm founder. Founder-as-monk still applies: the demanding daily user is the person already burning inference.

## Act 3 — convert later

No sales motion. No enterprise packaging until a monk cannot live without the wrap.

Cursor cloud VMs do not wrap the model path. That is already proven. CLI-only users are first-class.

## The loop

Growth and moat are the same engine:

better intercept → more usage → more fingerprints / excerpts / accept-reject of waste → better intercept.

## Honesty (same lock as the North Star)

Bounded excerpts may leave the machine. Full transcripts, system/developer messages, and keys must not.

Savings dollars are measured, never invented.

Product progression stays Observe → Diagnose → Optimize → Autopilot.

## How to use this file

Before a product change, ask: is this wrap / intercept, or plugin / demo / sales?

If the latter, do not ship it.
